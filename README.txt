TOKU Lite v2

目的
- 無料クーポン
- ドラッグストア割引
だけに絞った無料版PWAです。

使い方
1. 「今日の無料クーポン・割引を調べる」を押す
2. 検索文がクリップボードへコピーされ、ChatGPTを開く
3. ChatGPTで貼り付けて送信
4. 回答をコピーしてTOKUへ戻る
5. 「クリップボードから貼り付け」→「今日の結果として保存」

特徴
- 有料APIなし
- 地域とよく使うドラッグストアを端末に保存
- 過去14件の調査結果を端末内に保存
- iPhoneではChatGPTアプリ起動を試し、失敗時はWeb版へ
- PCではChatGPTを別タブで開く


v2.1
- 各コンビニの「プライチ」「1個買うと1個もらえる」「レシート無料引換券」を追加。
- セブン-イレブン、ファミリーマート、ローソン、ローソンストア100、ミニストップ、デイリーヤマザキ、NewDaysを標準対象。
- 購入期間と無料引換期間を別々に確認。
- 各社の最新公式情報だけを使うよう検索条件を強化。


v2.2
- 完全無料のまま、ChatGPT回答をTOKUへ1タップ取込。
- ChatGPT回答末尾のTOKU_DATA(JSON)を自動解析。
- 無料クーポン / ドラッグストア / コンビニ・プライチへ自動分類。
- 店名、内容、購入期間、引換期限、受取方法、条件、公式リンクをカード表示。
- 過去14回分の調査履歴を端末内保存。


v2.3
- iPhoneでChatGPTが2つ開く問題を修正。
- iPhone/iPadではChatGPTアプリを1回だけ起動。
- Web版への自動フォールバックを停止。
- 必要な場合だけ「Web版ChatGPTを開く」を手動で使えるように追加。


v2.4
- 初回限定、新規登録限定、新規会員限定、初回アプリDL限定、初回利用限定を除外。
- 新規カード発行・新規決済サービス登録が条件のものも除外。
- iPhoneで検索ボタンを押した後、ChatGPTアプリをより早く開くよう処理を軽量化。


v2.5 中国地方版
- ドラッグストア割引は中国地方（鳥取・島根・岡山・広島・山口）限定。
- 全国キャンペーンでも中国地方の対象店舗で使えることを公式確認できたものだけ掲載。
- 優先地域を入力すると、その県・市で使えるものを優先。
- ザグザグ、ウォンツ、ドラッグストアモリ、ひまわり等を追加。
- 無料クーポンとコンビニのプライチは全国対象のまま。
