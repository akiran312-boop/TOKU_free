TOKU 無料iPhone版

・OpenAI APIは使いません
・追加料金なし
・GitHub Pagesだけで動きます
・iPhoneのSafariから「ホーム画面に追加」でアプリ化できます

使い方
1. GitHubのTOKUリポジトリで index.html / manifest.json / service-worker.js / icon-180.png / icon-512.png をこの版に差し替える
2. .github フォルダと scripts フォルダは削除
3. deals.json も不要
4. GitHub Pagesを有効化
5. iPhoneのSafariでTOKUのURLを開く
6. 共有 → ホーム画面に追加
